## 추가 수정: 회전·지층 편집

H형 도면 윤곽은 개별 최장선 대신 방향별 선 길이 합계로 플랜지 축을 판별한다. CAD 블록 안에서 H형 윤곽을 판별할 수 있으면 블록 삽입점 대신 그 윤곽의 중심·방향을 사용한다. 배치 패밀리의 실제 상부 단면도 같은 방식으로 읽어 방향 차이를 회전값으로 적용한다. 판별 불가 형상은 기존 블록 방향과 사용자 각도 보정을 사용한다. 실제 복잡한 도면 전체의 누락/오인식 여부는 별도 확인이 필요하다.

경로 단면 창의 별도 매개변수 적용 버튼은 제거했다. 드롭다운을 바꾸면 해당 유형의 적용 예정값이 자동 갱신되며 단면 생성/높이 적용 시 사용한다.

PDF 독립 지층은 시추공별 수평 구역의 층 상단·하단을 이용해 지형솔리드로 작성한다. 같은 높이 구역을 합치고, 두께와 재질이 지정된 전용 유형을 만들며 생성 체적을 계산값과 대조한다. 기존 생성 지층은 성공한 트랜잭션에서 교체된다. 하위요소를 수정하면 원래 PDF의 해석 형상과 달라지므로 수정 후 중복체적은 다시 기록해야 한다. 상부 점 수정이 다른 지층을 자동 수정하지는 않는다.

## 굴착 구역

외곽선과 CAD 사면 구분 레이어를 고른 후 연결 오차를 mm로 입력한다. 기본 2mm이며 0이면 자동 연결하지 않는다. 작은 틈과 선 끝이 다른 선에 거의 닿는 지점을 지정 오차 안에서 연결해 구역을 계산한다. 원본 CAD는 변경하지 않는다. 서로 가까운 별도 선이 연결될 수도 있으므로 오차는 작게 지정하고 확인창의 구역 수와 면적을 검토한다.

구역 생성 버튼을 누른 뒤 만들 구역 내부를 차례로 클릭한다. 같은 구역을 다시 클릭하면 선택이 해제된다. Revit 선택 안내에 현재 선택 개수가 표시된다. Esc로 선택을 끝내고 구역 수와 전체 면적을 확인하면 별도 바닥 또는 지형솔리드로 한꺼번에 생성한다. 한 번에 생성하는 구역에는 화면에서 지정한 동일한 상단 EL이 적용된다.

## 수직부재와 높이 조정

CIP와 H-PILE은 좌표계 정보가 없는 일반 프로젝트에서도 CAD와 같은 Revit 내부 좌표로 생성한다. 공유좌표를 설정하지 않는다. 자동 결합으로 신규 수직부재가 기존 CIP/H-PILE과 잘린 경우 결합을 해제하고 실제 높이를 검증한다.

경로 단면·시트 창에서 수직부재를 선택하면 패밀리 유형별로 현재 저장된 길이와 상단 EL 매개변수를 확인하고 변경할 수 있다. 길이는 변경 가능한 인스턴스 길이 매개변수여야 하며, 상단 EL은 필요한 패밀리에만 선택한다. 패밀리 유형별로 매개변수를 고르고 적용한 다음 높이 적용을 실행한다. 두 레벨 기반 패밀리는 레벨 오프셋을 사용한다. 패밀리마다 기준점과 매개변수의 의미가 다를 수 있으므로 실제 배치 결과를 확인한다.

기존 자동 선택 후보는 길이 `Depth`, `깊이`, `길이`, `Length`, `높이`, 상단 `TOP`, `상단EL`, `상단 표고`이며 실제 선택된 이름은 각 부재에 저장된다. 패밀리에서 같은 이름이 두 개이거나 수정할 수 없는 매개변수는 적용되지 않는다.
