# 토공사 애드인 간단 사용 안내

## 시작하기

Revit 2027에서 프로젝트를 열고 **토공사** 탭을 선택합니다. CAD를 쓰는 기능은 도면을 먼저 링크하거나 가져옵니다. 패밀리 배치는 사용할 패밀리를 프로젝트에 먼저 로드합니다. 창이 열린 상태에서도 Revit 뷰를 바꿀 수 있습니다.

## 지형과 굴착면

- **SHP 지형·도로 주변건물:** SHP 도엽을 담은 상위 폴더, 지형 유형, 도로 유형, 건물 재질을 선택합니다. 원본 좌표를 축척 비율로 확대하지 않습니다.
- **CAD 경계 굴착면 작성:** 평면 CAD와 사면 구분선 레이어를 고릅니다. CIP 중심 또는 작업 외곽에 그린 Revit 선들을 선택해 닫힌 외곽을 지정하고, 만들 구역 안을 클릭합니다. 요소 유형과 초기 EL을 확인해 생성한 뒤 Revit 하위요소 수정으로 높이를 조정합니다.
- CAD에 사면 표시선이 구분선과 같은 레이어로 섞이면 구역이 잘게 나뉠 수 있습니다. 필요한 경계선만 별도 레이어로 정리하고 선택 면적을 확인하세요. 선 사이의 틈은 자동으로 연결하지 않습니다. CAD EL이나 경사 높이를 자동으로 판독하지 않습니다.

## 가시설

- **CIP 일괄 배치:** CAD, 원이 있는 레이어, 패밀리 유형을 고르고 배치합니다. 초기 EL은 임시값으로 표시됩니다.
- **H-PILE 인식·회전:** CAD, H형 선이나 블록의 레이어, 패밀리 유형과 필요한 회전 보정각을 고릅니다.
- **경로 단면·시트 높이 맞춤:** 평면의 CAD 폴리선 또는 연결된 Revit 선을 선택하고 CIP/H-PILE을 선택한 뒤 단면·시트를 만듭니다. 시트에 전개도를 mm 단위로 맞춰 링크하고, 목표 높이를 따라 Revit 상세선을 그립니다. 상단 또는 하단을 선택하고 기준선 선택 → 높이 적용을 누릅니다. 새 작업 시트의 단면 축척은 1:1입니다. CAD의 시작점·방향·EL을 직접 맞춰야 합니다.
- **STRUT·띠장 전개도 다단:** CAD 평면 중심선과 패밀리를 고르고, 단면 시트에 그린 단별 중심높이선을 선택합니다. 평면에서 영역을 검토한 뒤 생성합니다. 경사 버팀대 자동 배치는 아직 지원하지 않습니다.

## 지층과 확인

추가 도구에서 시추 PDF를 불러온 뒤 공번·좌표·표고·층서를 검토하고 지층을 생성합니다. 지형/지층 중복체적 기능은 현황과 굴착 후의 값을 각각 기록합니다. PDF 자동 인식은 양식에 따라 오류가 있을 수 있어 확인이 필요합니다.

도면과 패밀리마다 구성과 단위가 다를 수 있습니다. 작업 전에 복사본으로 시험하고 생성된 위치·높이·형상 및 수량을 확인하세요. 현재 1:1 시트와 개별 수평부재 기능은 검증했으나 임의 도면 전체 자동 해석은 지원하지 않습니다.
