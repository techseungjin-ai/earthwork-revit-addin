# 토공사 애드인 간단 사용 안내

## 시작하기

Revit 2027에서 프로젝트를 열고 **토공사** 탭을 선택합니다. CAD를 쓰는 기능은 도면을 먼저 링크하거나 가져옵니다. 패밀리 배치는 사용할 패밀리를 프로젝트에 먼저 로드합니다. 창이 열린 상태에서도 Revit 뷰를 바꿀 수 있습니다.

## 지형과 굴착면

- **SHP 지형·도로 주변건물:** SHP 도엽을 담은 상위 폴더, 지형 유형, 도로 유형, 건물 재질을 선택합니다. 원본 좌표를 축척 비율로 확대하지 않습니다.
- **CAD 경계 굴착면 작성:** 평면 CAD와 사면 구분선 레이어를 고릅니다. CIP 중심 또는 작업 외곽에 그린 Revit 선들을 선택해 닫힌 외곽을 지정하고, 만들 구역 내부를 차례로 클릭합니다. 같은 구역을 다시 클릭하면 선택이 해제됩니다. Esc로 선택을 마친 후 총 구역 수와 면적을 확인해 한꺼번에 생성합니다. 요소 유형과 초기 EL을 확인해 생성한 뒤 Revit 하위요소 수정으로 높이를 조정합니다.
- CAD에 짧은 사면 표시선이 구분선과 같은 레이어로 섞이면 최소 선 길이(mm)를 입력해 제외할 수 있습니다. 미세한 틈은 연결 오차(mm) 안에서 연결합니다. 기본 2mm, 허용 범위는 0~500mm이며 0은 자동 연결 해제입니다. 생성 전에 구역과 면적을 확인하세요.

## 가시설

- **CIP 일괄 배치:** CAD, 원이 있는 레이어, 패밀리 유형을 고르고 배치합니다. 초기 EL은 임시값으로 표시됩니다.
- **H-PILE 인식·회전:** CAD, H형 선이나 블록의 레이어, 패밀리 유형과 필요한 회전 보정각을 고릅니다.
- **경로 단면·시트 높이 맞춤:** 평면의 CAD 폴리선 또는 연결된 Revit 선을 선택합니다. 전개 방향을 맞춰야 하면 1-1번에서 시작점과 진행 방향을 지정합니다. CIP/H-PILE을 선택한 뒤 단면·시트를 만듭니다. 새 단면의 축척은 1:1입니다. 시트에 전개도를 mm 단위로 링크해 시작점·방향·EL을 맞춘 뒤, 목표 높이에 Revit 상세선을 그립니다. 상단 또는 하단을 고르고 기준선 선택 → 높이 적용을 누릅니다. 사용자 패밀리의 높이 매개변수는 4번 아래의 스위치를 켜면 지정할 수 있습니다.
- **STRUT·띠장 전개도 다단:** 평면 CAD와 패밀리 유형을 고르고, 단면 또는 시트에 그린 단별 중심 높이선을 선택합니다. 평면으로 돌아가 4번 **CAD 중심선 직접 선택**을 누른 뒤 같은 레이어의 배치선을 클릭하고 완료합니다. 레이어는 선택한 선에서 자동으로 채워집니다. 영역 안을 한꺼번에 검토하려면 레이어를 지정하고 다른 4번 버튼을 사용합니다. 검토한 부재 수와 EL을 확인한 뒤 5번 **생성 / 갱신**을 누릅니다.
- **어스앵커·락볼트:** 부재 종류와 점 기반 일반모델 패밀리를 고릅니다. CAD 선의 시작점 또는 끝점을 기준으로 지정하고, 선 안쪽으로 옮길 거리(mm)를 입력합니다. STRUT·띠장과 같이 단별 높이선을 선택하고 평면 배치선을 검토한 뒤 생성합니다.

## 지층과 확인

추가 도구에서 시추 PDF를 불러온 뒤 공번·좌표·표고·층서를 검토하고 지층을 생성합니다. 시추공 주변에 지형솔리드로 생성되며 선택 후 하위요소 수정으로 점 높이를 변경할 수 있습니다. 수정한 뒤에는 물량을 다시 계산하세요. 지형/지층 중복체적 기능은 현황과 굴착 후의 값을 각각 기록합니다. PDF 자동 인식은 양식에 따라 오류가 있을 수 있어 확인이 필요합니다.

도면과 패밀리마다 구성과 단위가 다를 수 있습니다. 작업 전에 복사본으로 시험하고 생성된 위치·높이·형상 및 수량을 확인하세요. 현재 1:1 시트와 개별 수평부재 기능은 검증했으나 임의 도면 전체 자동 해석은 지원하지 않습니다.
