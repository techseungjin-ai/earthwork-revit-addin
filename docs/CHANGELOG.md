# 변경 이력

## 0.4.2 — 2026-11-08

- STRUT·띠장 및 어스앵커·락볼트 4번 직접 선택에서 레이어 사전 입력을 생략할 수 있습니다. 클릭한 CAD 중심선의 레이어를 자동으로 읽고 고른 선만 배치합니다. 영역 일괄 검토는 레이어를 지정해야 합니다.
- STRUT·띠장은 좌표계를 설정하지 않은 프로젝트에서도 Revit 내부 좌표로 배치할 수 있습니다.
- 경로 시작점과 전개 방향을 지정할 수 있습니다. 시트의 단면 폭을 각 경로 구간 길이에 맞추고, 높이 매개변수 사용자 설정은 기본으로 숨깁니다.
- 굴착 경계선의 연결 허용 오차를 최대 500mm로 늘리고 짧은 CAD 선을 제외하는 설정을 추가했습니다.
- 어스앵커·락볼트는 한 명령에서 선택하며 CAD 선의 시작점 또는 끝점과 오프셋을 사용합니다.
- 지형 표면 복사와 SL 분할 지형 병합은 검증 중이어서 실행이 비활성화되어 있습니다.

## 0.4.1 — 2026-11-06

- 굴착 구역 다중 클릭 일괄 생성, CAD 미세틈 연결 오차 입력.
- 좌표계 없는 프로젝트의 CIP/H-PILE 배치 오류 수정 및 자동결합 절단 방지.
- H형 도면 윤곽과 실제 패밀리 단면 방향을 비교해 회전 보정.
- 높이 매개변수 선택 자동 반영, 별도 적용 버튼 제거.
- 시추 PDF 지층을 하위요소 편집 가능한 지형솔리드로 생성하고 체적 검증.
- 실제 Revit 복사본에서 지층29개/CIP1/HPILE5/굴착지형2 검증. 임의 도면 전체 자동 해석은 별도 확인 필요.

# 변경 기록

## 0.4.0

- SHP 대지 생성 회전각 추가. 통합 SHP 중심 기준 +반시계/-시계이며 Revit 진북/도북·공유좌표 설정을 변경하지 않음.
- 저장한 공통 원점/회전을 지형·도로·건물, 시추 위치와 지층, CIP의 최근접 시추 판정에 적용.
- 도로/건물 경계 정리 후 전체를 회전해 회전에 따른 단순화 차이를 방지.
- Revit 도로의 삼각분할 불가 극소면 처리와 생성 후 실제 도로 피복 면적 검사 추가.
- 작업대지 창에 적용 회전값과 굴착량 기준 설명 추가. QUANTITIES.md에 계산식·전체/굴착 체적 차이·예시·제한 기록.

## 0.3.0

- 기능창을 ExternalEvent 기반 모델리스로 변경. Revit 뷰 전환·화면 선택과 함께 사용하며 문서 격리·취소 후 재시도 지원.
- CAD·레이어·패밀리 드롭다운에 화면 선택과 새로고침 추가. 지원되지 않는 멀리언 유형 제외.
- 시추 PDF의 편집 검토 표와 자동 JSON 연결. 수동 변환 과정 제거.
- 작업대지에서 원본 지형 선택, 시추공 위치 보기, 경계 방식, EL/깊이 계산, 예상 물량 검토 제공.
- 예전 시험값 -10 기본 입력 제거. 작업경계·바닥 EL·시추자료 경로 저장.
- 다른 PC용 설치/로드 해제 스크립트, payload 해시 검증, 설치·사용·테스트 문서 포함.

## 0.2.0

- SHP 폴더 기반 지형·도로 구획·주변 건물, 축척 입력 및 TIN 범위 자르기.
- 최근접 시추공 기반 작업지층 솔리드와 지층별 굴착 물량표.
- CIP/H-PILE 평면 인식·유형 선택·회전, 전개도 깊이 대응, STRUT/띠장 다단, CIP 지층 분할.
- 도로 구획 병합, 지형점 XY 이동 및 측량 문자 표고 반영.
- 공유좌표 자동 설정 제거, 사용자 수동 좌표 조정 흐름 적용.
